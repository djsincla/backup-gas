BackupGAS

Back up Google Apps Script projects that Google gives you no way to download — including the scripts attached to a Sheet, Doc or Form.

Install View on GitHub

The problem

A script attached to a spreadsheet isn't a Drive file, so Drive can't export it. The script editor has no download button. And the one remaining route — the Apps Script API — needs a Google Cloud project, which plenty of managed accounts aren't allowed to create.

RouteBound scriptsBlocked when
Drive download or exportNoAlways — bound scripts aren't Drive files
Apps Script API (clasp, scripts)YesYour account can't enable the API in a Cloud project
BackupGASYesNever — it reads the editor page you already have open

If you've seen Apps Script API has not been used in project NNNN before or it is disabled and had no way to fix it, this is for you.

What it looks like

Open a project in the editor, click the icon, and every file is saved under its own name.

Install

Not on the Chrome Web Store yet, so load it unpacked:

  1. Download the repository: backup-gas.zip, and unzip it.
  2. Open chrome://extensions.
  3. Turn on Developer mode, top right.
  4. Click Load unpacked and choose the folder.
  5. Pin it from the puzzle-piece menu.

Use it

  1. Open a script — in a Sheet that's Extensions → Apps Script — and let the page finish loading.
  2. Click the BackupGAS icon.
  3. Choose Download to this computer, or Save to Google Drive once the receiver below is set up.

Downloads land in Downloads/Apps Script Backups/<project> <timestamp>/, one file per script file, keeping real names like Code.gs and Index.html.

Saving to Google Drive

A Chrome extension can't write to Drive without a Cloud OAuth client — the same wall this tool exists to avoid. So the extension hands the files to a small Apps Script web app that you deploy, which writes them to your own Drive with ordinary Drive access.

  1. Open script.new, paste in receiver/Code.gs, save.
  2. Deploy → New deployment → Web app. Access: Anyone, or your own organization if that's all your admin allows.
  3. Open the /exec address it gives you and copy the setup line it shows.
  4. Paste that line into the extension's Settings.

Backups then appear in My Drive/Apps Script Backups/<project>/<timestamp>/.

On the password. The receiver generates one itself and shows it once, on the first visit to its address. It rejects any request without it, only ever creates files, and writes only inside its own backup folder. Keep the setup line private.

How it works

The Apps Script editor is a Monaco editor, and it already holds every file of the open project — that's what you're looking at. Each entry in the file list carries a data-res-id attribute matching a Monaco model, so the extension pairs each file name with its contents and reads the text straight from the page.

No API, no Cloud project, no admin involvement. It also means an export contains exactly what the editor shows, unsaved edits included.
