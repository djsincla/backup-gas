    The editor has your code. Now you can keep it.

    BackupGAS is a Chrome extension that saves every file of the Apps Script project you have open — to Google Drive, or to your computer — including the scripts attached to a Sheet, Doc or Form.

    No API. No Google Cloud project. No admin involvement. It reads the editor page you already have open, which is the one route nobody can switch off.

    // Why getting your own code out of Apps Script is hard

    Three routes, two of them closed

    A script attached to a spreadsheet isn't a Drive file, so Drive can't export it. The editor has no download button. That leaves the Apps Script API — which needs a Google Cloud project, and plenty of managed accounts aren't allowed to create one.

    RouteBound scriptsBlocked when
    Drive download or exportnoAlways — bound scripts aren't Drive files
    Apps Script API, claspyesYour account can't enable the API in a Cloud project
    BackupGASyesNever — it reads the editor page

    If you have ever seen Apps Script API has not been used in project NNNN before or it is disabled and had no way to fix it, that dead end is what this exists for.

    Install

    Not on the Chrome Web Store yet, so load it unpacked:

    1. Download the repository zip and unzip it.
    2. Open chrome://extensions.
    3. Turn on Developer mode, top right.
    4. Click Load unpacked and choose the folder.
    5. Pin it from the puzzle-piece menu.

    Using it

    1. Open a script — from a Sheet that's Extensions → Apps Script — and let the page finish loading.
    2. Click the BackupGAS icon.
    3. Choose Download to this computer, or Save to Google Drive.

    Files land in Downloads/Apps Script Backups/<project> <timestamp>/, one per script file, under their real names.

    // Optional: send backups straight to your own Drive

    Saving to Google Drive

    A Chrome extension can't write to Drive without a Cloud OAuth client — the same wall this tool exists to avoid. So it hands the files to a small Apps Script web app that you deploy, which writes them to your Drive with ordinary Drive access.

    1. Open script.new, paste in receiver/Code.gs, save.
    2. Deploy → New deployment → Web app. Access: Anyone, or your organization if that's all your admin allows.
    3. Open the /exec address it gives you and copy the setup line shown there.
    4. Paste that line into the extension's Settings.

    Backups then appear in My Drive/Apps Script Backups/<project>/<timestamp>/.

    About the password. The receiver generates one itself and shows it once, on the first visit to its address. It refuses any request without it, only ever creates files, and writes only inside its own backup folder.

    How it works

    The Apps Script editor is a Monaco editor, and it already holds every file of the open project — that is what you are looking at. Each entry in the file list carries a data-res-id attribute matching a Monaco model, so the extension pairs every file name with its contents and reads the text straight from the page.

    That also means an export contains exactly what the editor shows, unsaved edits included.

    Permissions

    PermissionWhy
    scriptingRead the file list and contents from the open editor tab
    downloadsSave files to your Downloads folder
    storageRemember your receiver address and password
    script.google.comThe only site it runs on

    No analytics, no servers. Nothing leaves your machine except the files you send to your own receiver.
